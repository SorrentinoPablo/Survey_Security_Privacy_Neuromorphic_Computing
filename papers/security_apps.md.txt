# Emerging Security Applications

[Back to Main README](../README.md)

This section lists papers related to emerging security applications in neuromorphic, in-memory, memristive, spintronic, optical, and device-level computing systems. Topics include Physical Unclonable Functions (PUFs), True Random Number Generators (TRNGs), in-memory cryptography, secure sensing, near-sensor security, and device-level security primitives.
